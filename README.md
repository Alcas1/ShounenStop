## Shounen Stop 
Website for sale of Japanese/Anime goods

---

How to install and run:

> 1. **Install** the [git](https://git-scm.com/downloads) version control manager
> 2. **Clone** this repository to your local machine using `git clone https://github.com/Alcas1/ShounenStop.git`
> 3. **Download** [Node.js](https://nodejs.org/en/download/) - this comes with the package manager, **npm**
> 4. **Navigate** to the repository you cloned locally using a command line tool, like **Git Bash**, **Terminal**, or **Command Prompt**
> 5. **Install** the required **npm** packages by using your command line tool of choice to run the command `npm install`
> 6. **Install** the required **Gatsby** CLI (Command Line Interface) using the command `npm install -g gatsby-cli` on Windows and `sudo npm install -g gatsby-cli` on UNIX systems
> 7. **Build** the application using the command `gatsby build`
> 8. **Launch** the application using the command `gatsby develop`
> 9. **Test** the application at `http://localhost:8000/`

Note: If `gatsby build` fails because "error:0308010C:digital envelope routines::unsupported", run `export NODE_OPTIONS=--openssl-legacy-provider` and try again
